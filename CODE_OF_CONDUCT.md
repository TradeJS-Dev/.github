# TradeJS Code of Conduct

## Our Standard

TradeJS is an open-source project. We expect contributors and maintainers to make participation respectful, constructive, and technically honest.

Examples of behavior that contributes to a positive environment:

- Showing empathy and respect toward other people
- Giving and receiving technical feedback in good faith
- Focusing discussions on facts, tradeoffs, and project goals
- Accepting responsibility and correcting mistakes promptly
- Helping keep discussions accessible to new contributors

Examples of unacceptable behavior:

- Harassment, personal attacks, or discriminatory language
- Trolling, baiting, or deliberately inflammatory behavior
- Publishing private information without permission
- Repeatedly derailing technical threads with bad-faith argument
- Any conduct inappropriate for a professional open-source community

## Scope

This Code of Conduct applies in:

- GitHub issues, pull requests, and discussions
- project documentation and review threads
- public and private spaces when someone is representing the TradeJS project

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct and may remove, edit, or reject comments, commits, code, issues, discussions, or pull requests that are not aligned with it.

## Reporting

If you need to report unacceptable behavior, do not escalate the situation in public.

Contact the maintainers privately through GitHub by reaching out to the organization owners or repository admins.
